# ST Direct Event (随机事件投放器 / 跑团后台事件导演)

SillyTavern 的高沉浸感分轮事件推演扩展。采用独特的**“一轮生成，多轮享受”**与**“小纸条暗箱机制”**，由副模型一次性推演出完整剧本脉络与隐秘暗箱，酒馆主模型随对话轮次逐步解封执行，彻底杜绝主模型自说自话、战力崩塌与高延迟等问题。

---

## 核心特色机制

### 1. 一轮生成，多轮享受 (One-Shot Generation, Multi-Turn Progression)
* **超低延迟与因果连贯**：传统事件插件每轮都频繁请求外部模型，延迟极高且容易剧情脱节。ST Direct 仅需副模型（如 agy-gemini-3.8-flash-high / Claude 等）执行单次快速推理，即可推演出完整的连续事件链条（包含后台暗箱、分轮推进小纸条与终局判定条件）。
* **全流程零剧透推进**：整套事件档案保存在插件聊天数据中，主模型和聊天框完全零剧透。每轮对话插件仅向主模型秘密递送当前轮次的“小纸条”，终局前绝不泄露后续分支与暗箱机密。
* **自由伸缩的博弈节奏**：支持一键切换「1回结」（单回即时决胜）、「3回速决」（紧凑交锋）、「6回推演」（标准剧情弧线）以及 1～30 回合自定义步进调节，适配短平快与长篇跑团不同场景。

### 2. 小纸条暗箱机制 (Action Hook 与客观外部推力)
* **客观外部推力铁律**：小纸条绝对严禁代写、预设或脑补玩家的任何言行、招式、内心或态度（严禁出现“面对你的反击/在你的质问下/你警惕地后退……”等假定玩家言行的句子）。
* **聚焦两项客观要素**：
  1. **客观环境剧变/物理危机**：不可逆的物理变故、时间流逝、地形破坏、敌方增援或意外阻碍；
  2. **NPC 的主动作为与战术施压**：NPC 基于自身动机主动出招、逼近或试探。
* **结尾精准留钩 (Action Hook)**：每张小纸条结尾必须停留在 NPC 的具体攻防动作或抉择点，把完整的应对权与拆招空间留给玩家；终局依据玩家前几轮的真实言行公正裁决走向（Good End / Bad End）。

### 3. 战斗特化：第三方新势力与敌方身份全链路通报
* **全新第三方势力空降**：支持勾选「非上下文新势力」，上下文仅供情境底色参考，绝对禁止擅自挪用上文已有弱小配角或同伴变“五五开强敌”，必须为空降的陌生独立势力。
* **战力天平与势力库管理**：支持保存、选择常用势力，严格锁定对手名称、战力等级、能力风格与弱点盲区，杜绝战力忽高忽低的机械膨胀。
* **敌方身份明确通报（拒绝无名黑影）**：
  * 硬性要求副模型在暗箱首行以固定格式通报：`【登场对手身份】：<具体姓名/代号>（所属势力：...，定位战力：...，装束动机：...）`；
  * 首轮纸条突发敌袭时必须明确交代这是谁，严禁整篇只用“黑衣人”、“刺客”糊弄；
  * 生成通知（Toast）、事件卡片徽章、展开详情行及大纲暗箱弹窗全链路直观显示对手身份。

### 4. 恋爱特化：动态识别真实女主，彻底根除“和故事名字谈恋爱”
* **智能识别上下文真实人物**：酒馆许多角色卡名实际是故事名、章节名或模组名（如《第一章：初遇雪原》）。在恋爱子菜单中未指定女主时，系统通过专门规约自动从近期上下文实际对话与互动的真实女性角色中识别对象。
* **防故事名恋爱双重防线**：在系统指令与用户提示词顶部注入警示，严禁把卡片标题、剧名或地名当成角色名字谈恋爱。
* **唯一核心女主锁定**：亦支持手动指定唯一女主，杜绝路人 NPC 抢戏拉偏情感线。

### 5. 世界书副 API 注入管理与即时搜索过滤
* **常驻蓝灯精准提取**：副 API 默认自动读取并注入世界书中的常驻蓝灯条目，确保副模型理解核心世界观。
* **条目级自定义编辑**：支持单独勾选/排除特定条目、对酒馆原生条目标题正文进行重写覆盖，以及随时新增插件专属的自定义条目。
* **实时模糊搜索与动态计数**：世界书弹窗内置即时搜索框，支持同时对条目标题、关键词与正文设定进行模糊过滤，未命中条目即时隐藏，并动态显示匹配计数（如：共 25 条，匹配 3 条）。

### 6. 纯文学小说破限与去主角化叙事准则
* **万字纯文学小说预填充破限**：内置万字小说《雪融雪降》（冬马和纱人设与校园日常）高强度破限文本，越过出厂保守和谐倾向。
* **去主角化与防谄媚**：平等看待玩家角色与 NPC，尊重因果逻辑，不无理偏袒玩家，不机械化对白，严禁实验报告式语言。
* **感官与暗黑叙事豁免**：涉及肢体创伤、暴力交锋、惊悚暗黑或情感拉扯场景时保持客观冷峻，杜绝空洞辞藻与道德说教。

### 7. 全流程可视化与事件管理
* **分轮大纲与暗箱弹窗**：随时查看当前执行的小纸条、后台暗箱核心机密、四分支/双分支结局走向以及副模型生成的原始完整文本。
* **一键清空事件**：事件列表配备「一键清空事件」红色按钮，带防误触确认，并在清空时自动安全注销酒馆底层注入，杜绝提示词残留污染。
* **提示词查看器 (Prompt Viewer)**：支持离线与无网络环境下完整预览发往副 API 的全套请求报文（系统指令、小说破限、细分流派规则、世界书条目、上下文），支持按角色分块折叠与全文搜索。
* **多套精致主题与悬浮胶囊 (FAB)**：内置深海蔚蓝、樱花梦境、未来科幻、复古羊皮、极简极夜、暮色紫晶、翡翠林境等 7 款通透主题；悬浮胶囊实时显示事件推进进度（如 `2/3`），支持一键跳至终局收束。

## 快速上手与使用指南

### 安装方法
1. 打开 SillyTavern，进入扩展管理界面（Extensions）；
2. 在「通过 URL 安装扩展」中填入本仓库地址：
   `https://github.com/pzwtxdy831-commits/st-direct-event`
3. 安装完成后刷新页面即可看到右侧浮动胶囊（FAB）。

### 默认推荐配置
* **辅助模型**：`agy-gemini-3.8-flash-high`
* **请求方式**：支持酒馆代理（Proxy）、浏览器直连（Direct）与自动适配（Auto）。使用酒馆代理需在 SillyTavern 根目录 `config.yaml` 中设置 `enableCorsProxy: true` 并重启酒馆服务。
* **最大输出**：`40000`
* **温度**：`0.8`
* **默认回合**：`8`
* **主题**：深海蔚蓝
